# Yokwe — Семейный органайзер с виртуальным питомцем

## О проекте

**Yokwe** — это мобильное приложение для совместного планирования задач, объединяющее двух пользователей в общее семейное пространство. Помимо синхронизированного списка целей, в приложении живёт виртуальный питомец, чьё поведение и реплики динамически меняются в зависимости от активности пользователей. Проект выполнен в рамках обучения по курсу «Android разработчик» в TeachMeSkills.

## Основные возможности

### Синхронизация пользователей
- **Авторизация пользователей через Firebase Authentication**.
- **Пригласительная система** — первый пользователь генерирует уникальный код, по которому второй участник присоединяется к семейной группе.
- **Общее пространство** — после связывания аккаунтов данные становятся доступны всем пользователям семейной группы и синхронизируются через Firestore.

### Управление общими целями
Три типа задач, охватывающих разные аспекты повседневной жизни:
- **Финансовая** — для учёта накоплений.
- **Разовая задача** — любое однократное дело.
- **Привычка** — ежедневное повторяющееся действие.

### Виртуальный питомец
- **Генерация реплик через OpenRouter API** — питомец комментирует каждое действие с задачами, используя модель DeepSeek-V3-0324.
- **Система прогрессии** — выполнение задач повышает уровень питомца.
- **Динамический промпт** — с ростом уровня меняется характер и стиль общения питомца, что достигается модификацией системного промпта, отправляемого в API.

### Главный экран
- **Статистика выполнения задач** — наглядная сводка активности.
- **Лента последних событий** — текстовый лог действий в семейной группе.
- **Карточка питомца** — отображение текущего уровня и последней реплики.
